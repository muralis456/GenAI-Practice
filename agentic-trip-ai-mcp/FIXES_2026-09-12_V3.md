# AgenticTripAI V3 fixes — 2026-09-12

## Runtime/compiler
- Fixed `HotelAgentService` lambda compilation failure by using a final normalized destination.
- The previous runtime error was caused by reassigning `destination` and then capturing it in a stream lambda.

## Destination / airport
- Route destination extraction now strips travel constraints such as `within the budget 2L`, `for 5 days`, and follow-up instructions.
- The request `from bangalore to dubai within the budget 2L...` now produces destination `Dubai`.
- Flight and airport nodes prefer the clean destination from the current request over stale/over-broad state.
- Blank or malformed airport queries are not sent to the MCP resolver.

## UI
- Desktop keeps the original left sidebar/two-pane layout.
- Sidebar is fixed at 300px; the main conversation consumes all remaining width.
- Removed max-width restrictions from the main conversation/result area that caused the large blank area.
- Composer fills the available main area.

## Error security
- SSE `failed` events now contain only a generic user-safe message.
- REST exception handler no longer returns raw `IllegalStateException` messages.
- Browser error handling never renders exception messages/stack traces.
- Full exception diagnostics remain in server logs only.
